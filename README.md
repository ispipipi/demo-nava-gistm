# GISTM Tracker Nava

Demo funcional modular para seguimiento GISTM.

## Stack

- React 18
- Vite
- TypeScript
- Tailwind CSS
- Zustand con persistencia en `localStorage`

## Scripts

```bash
npm install
npm run dev
npm run lint
npm run build
```
